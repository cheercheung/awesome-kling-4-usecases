Each public source record retains its own capture timestamp where supplied.

## Cases and grouping

The 170 posts contained 165 video-bearing posts. Exact media hashes, duration and visual fingerprints were used to consolidate reused clips and encodings, followed by per-group visual review. That produced 87 material groups: 80 generated-demo groups, three workflow presentations and four general introductory or promotional montages.

The repository keeps **83 concrete cases** and excludes the four general montages (`D12`, `D43`, `D61`, `D80`). Source group identifiers remain separate from contiguous public case numbers. Cases are ordered by task category, then stable group identifier; engagement does not determine editorial order.

Several King Cards entries are different excerpts from the same film. Some other groups also have multiple distribution posts. A material group is not proof of a unique original project, an independent generation or a successful API call. The credited account is the source posting account unless the source establishes more.

## Prompt coverage

There are **11 exact public Prompt spans across 10 cases**: two in root-post text, seven in author-reply text and two transcribed from author-reply images. Nine Prompt-lead threads were checked; eight yielded actual instructions. The remaining thread described a workflow without publishing its generation Prompt.

Each Prompt retains its source URL, evidence type and text SHA256 in [case data](../data/use-cases.json). The two image transcriptions are accompanied by the author's four original reply images. Their embedded reference thumbnails are not substitutes for full input files. Other videos that display scrolling text do not become reproducible Prompt cases without a complete transcription.

## Evidence limits

Visual review supports scene descriptions. It does not independently verify model identity, API access, original authorship, speech accuracy, physical correctness, output resolution, billing, advertising results or generation duration. Edited films, compilations and author-reported prices are identified in case notes. No API generation was performed to establish this collection.
