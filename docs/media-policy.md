# Media and attribution policy

This repository presents source-backed video use cases. A case is a distinct scene, comparison, or documented workflow; several cases may refer to excerpts from the same longer film.

Every case retains the original public post, posting account, source date, and a playable source-derived video. The posting account is attribution for the cited post and is not a guarantee of original authorship or independent model execution.

README videos use a poster image linked to a playable HTTPS video. Public display and playback media are hosted in this repository's Cloudflare R2 namespace. Local working downloads and credentials are excluded from Git.

The two author replies containing shot-planning material retain all four original photos: two storyboard cards and two Prompt cards. Reference-image thumbnails inside a card are not represented as separately acquired original input images.

Third-party videos, images, prompts, product names and characters remain subject to their respective creators' rights. The repository's editorial license does not relicense those materials. Attribution, correction or removal requests can be filed as an issue in this repository with the relevant source and case number.

A visible clip establishes an output artifact, not a verified API invocation, a playable game, a production-cost comparison, or an advertising result. Any such additional claim requires its own evidence.
