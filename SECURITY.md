# Security

This is a static content repository. Do not put API keys, credentials or personal information in issues, pull requests, prompts or committed files. The project does not ask visitors to run a Kling installer or submit generation credentials.

If you discover a leaked credential in repository history, use the repository's private GitHub vulnerability reporting feature when available. Otherwise open an issue describing the affected path and commit without repeating the secret. Credential owners should revoke exposed credentials through their provider.

Third-party source and playback links are external resources. Report a changed or malicious destination with its affected case number and URL.
